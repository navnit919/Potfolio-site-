# Images

Drop your real photos and screenshots into this folder using the **exact file names**
below. As soon as a matching file exists, it replaces the styled placeholder
automatically — no code changes needed. If a file is missing, the placeholder just
stays, so the site always looks complete.

| File name          | Used for                         | Suggested size (px) | Shape        |
|--------------------|----------------------------------|---------------------|--------------|
| `profile.jpg`      | Your photo (About section)       | 800 × 1000          | Portrait 4:5 |
| `traffic.jpg`      | Traffic Violation Detection      | 1280 × 800          | Landscape    |
| `oa-screening.jpg` | Osteoarthritis Screening (SIH)   | 1280 × 800          | Landscape    |
| `drone.jpg`        | Multirotor UAV                   | 1280 × 800          | Landscape    |
| `rc-car.jpg`       | RC Car                           | 1280 × 800          | Landscape    |
| `ultrasonic.jpg`   | Ultrasonic Obstacle Detection    | 1280 × 800          | Landscape    |
| `python.jpg`       | Python Automation Tool           | 1280 × 800          | Landscape    |

Tips
- `.jpg`, `.jpeg` and `.png` all work — but keep the name and extension the same as above
  (the HTML points at `.jpg`). If your file is a `.png`, either rename it to `.jpg`
  or update the `src` in `index.html`.
- Keep each image under ~400 KB so the page loads fast. Free tools: squoosh.app or tinypng.com.
- The project cards are cropped to 16:10 and your photo to 4:5, so centre the subject.
